# SXXBookingSystem – US30

Individuell uppgift inom objektorienterad analys och design på Nackademin.

## User Story – US30
Personal söker efter bokning.

Syftet är att ta fram en systemdesign för en sökfunktion där personalen kan söka efter bokningar med hjälp av bokningsnummer eller kundens e-postadress.

## Innehåll
- Aktivitetsdiagram V1–V3
- Sekvensdiagram V1–V3
- Exporterade diagram i PNG-format
- Redigerbara originalfiler i PlantUML-format

De olika versionerna visar min utvecklingsprocess från första utkast till slutlig design.
